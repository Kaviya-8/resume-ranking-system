# Resume Ranking System & Mock Interview Platform

A web-based platform for automated resume ranking and candidate assessment, built with Python (Flask), MySQL, and HTML/CSS.

## Features
- Upload resumes and analyze them for ranking
- HR dashboard to manage candidates
- Aptitude and technical tests
- Mock interview module for candidate practice
- Track interview results and candidate progress

## Technologies Used
- Python (Flask)
- MySQL
- HTML, CSS
- REST APIs

## Installation
1. Clone the repository: `git clone https://github.com/Kaviya-8/resume-ranking-system.git`
2. Navigate to project folder: `cd resume-ranking-system`
3. Install dependencies: `pip install -r requirements.txt`
4. Set up MySQL database
5. Run the app: `python app.py`
6. Open `http://localhost:5000` in your browser
